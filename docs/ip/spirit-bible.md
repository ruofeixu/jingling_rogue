# 契灵志怪 — IP 圣经

## 世界观（一句话）

人间城邑与山野之间有「隙」，隙中精怪可被镇物暂契。玩家是游方契士，以一局长征收集契录，失败则局内队伍消散，契录仍在。

## 美术方向

**水墨志怪（2026-10-30 定稿，取代原卡通方向）。** 验收真源：[水墨观感规格](../superpowers/specs/2026-10-29-ink-design.md)。

精怪：**水彩加墨线**。毛笔勾线有粗细变化，墨色晕染出体积，再上淡彩；每只有一两处主色（灶狸的火焰朱橙、身体淡赭），其余是浓淡墨。仍是 Q 版全身、圆、好认，大眼睛可以保留。  
允许：毛笔飞白、墨色晕边、毛发笔触、流苏绳结等装饰。**内容上只禁止违反法律法规和侵犯他人 IP 的东西**（见下一段），其余不特意禁止，风格靠样张和定妆照统一。  
参考气质是"可爱的水墨小品"，不是碑刻暗调，也不是日式宠物。

禁止：官方宠物换色/换描边；别家角色换皮；常见官方龙/鼠/龟/蛙剪影。  
允许：原创剪影精怪（灶狸、井蛛、桃梗等）。

立绘：RGBA 透明底，禁止在图里烘焙圆形/椭圆垫底或纸底。选初始与战斗必须等比 contain，不得按框硬拉。同一只精怪在所有场合必须是同一个形象（见规格第 5 节"角色一致性"）。

炎、潮、岩、木、霆、霜、影、光。代码：`flame` `tide` `stone` `wood` `bolt` `frost` `shade` `light`。
