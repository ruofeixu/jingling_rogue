## 2. 原则

- 不开新玩法、不改观察面、不给策略看隐藏种族值
- 不为「更像官方 UI」改底栏或十八系
- 一次一块；R3、R4 各自只选 **一个** 候选
- 达不到高档通关只改公开口径，并在细计划写明差距，不改 `policies.ts`
- 文案走 spirit-bible；禁「闲术N」「落雁幼」这类生成器填料味（R4 新行必须像志怪名）
- 立绘仍走 remote，不进主包；`pnpm check:pack`

质量分层同质量规格：L1 无头必跑，L2 改 `assets/scripts/` 必跑，L3 不挡 L1。

## 3. 阶段（顺序固定）

依赖：R0 → R1 → R2。R3 在 R2 之后。R4 与 R3 不互相阻塞，仍一次只做一块。R5 最后。

### R0 预览不死

**Produces:** 进预览必有大厅，而不是黑屏或缩在中间一块。

必须：

1. `creator-entry.test.ts` 继续拒绝重复的 jinglingCore import。
2. `assets/scripts/Boot.ts` 使用 `ResolutionPolicy.EXACT_FIT`（写成测试：读文件断言字符串存在）。坐标仍只来自 `screenLayout`，禁止在 Boot 写死 x/y。
3. Canvas 运行时位置归零，内容尺寸等于当前设计分辨率（竖 750×1334 / 横 1334×750）。
4. 不改战斗公式、不加立绘、不调难度。

验收：`pnpm test`、`pnpm check:forbidden`。改了 Boot 则刷新 Creator 预览能看到标题「契灵志怪」与大厅按钮。

### R1 点得中

**Produces:** 竖+横主路径点了有下文；装饰不抢点击。

必须：

1. Q1 已有几何 / 死点击 / `probeWaitingUi` 门保持绿。
2. 可点控件 ≥44；`coverHit()` 仍包装饰。
3. 非法点（空地、尽术）有 log。本阶段不改公式。

验收：同质量规格第 3 节相关断言。

### R2 高档能通

**Produces:** 高策略经典 200 通关有数字；低/中档不掉出条带。

必须：

1. 先抄 40 种子改前表，再只拧公开口径（伤害、等级闸、双人率、战后回复、商店权重、波 21+ 敌等级）。
2. 低档 40 种子均波仍在 **10–30**（Q0 门）。中档 200 种子均波尽量留在 **40–60**。
3. 200 种子高档通关目标 **40%–60%**。进不去：只再拧伤害/回复/双人，写明差距，**禁止**改观察面、禁止开新系统。
4. 校准表写入该阶段细计划。

验收：`pnpm test`（含 bench 门）、`pnpm sim:bench --tier all --seeds 200` 数字进细计划。

### R3 观感一块

细计划只选下列 **一项**：

- 第三批 9 张 remote 立绘（RGBA、`PORTRAIT_IDS` 扩到 27），或
- 镇物/小药/契印/灵糖从 Graphics 换成远程小图（仍不进主包），或
- 受击/还魂预览 tween，时长可测

禁止官方宠物外形。PNG `color type = 6`。

### R4 表一块

细计划只选一张表并改 `catalog.test.ts` 地板：

- 术法 ≥280，或
- 魂契 ≥120，或
- 奇遇 ≥40

新行必须有志怪中文名与可用效果；禁止 `catalog_art_*` / `闲术N` 式填料。先 `pnpm check:forbidden`。

### R5 真机包

**Produces:** 微信、抖音开发者工具打开的包能看到大厅（标题或「新的旅途」），不是只打 `preview pack ready`。

允许：用 Creator 3.8.2 打正式小游戏包，或把预览壳打进包（Boot 能跑）。骨架 `pack:minigame` 可留作 CI 结构检查，但 **不得** 再当 R5 完成定义。不上架。`pnpm check:pack` 仍绿。

## 4. 明确不做

- 新模式、新境域玩法、聊天、支付
- 给 sim 策略隐藏种族值或未来波次
- 把 Funplay / 截图当唯一 CI
- 同一会话做完 R0 又开 R1（除非用户明确说继续）
- 往第 16 节加勾

---

## 5. 阶段完成的定义

一个 R 阶段完成 = 该阶段细计划全部勾完 **且**：

1. `pnpm test`、`pnpm check:forbidden` 通过
2. 改了 core → `pnpm sync:core`
3. 改了 UI → 质量规格第 3 节相关断言仍绿
4. 改了难度 → 本规格 R2 与 playability-bar 对应种子门仍绿，细计划有校准表
5. 验收句能在测试名字或脚本输出里找到
