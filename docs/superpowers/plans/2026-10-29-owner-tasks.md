## 二、备案下来之后（P5 开工前）

- [ ] **5. 申请 HTTPS 证书**：腾讯云免费 DV 证书即可。准备两个子域名，例如 `api.<域名>`（存档、登录）和 `pvp.<域名>`（对战长连接）。
  - 结果：子域名 ____
- [ ] **6. 配置合法域名**：微信小游戏后台「开发管理 → 开发设置 → 服务器域名」，抖音开发者后台同类位置。
  - `request` 合法域名：`https://api.<域名>`
  - `socket` 合法域名：`wss://pvp.<域名>`
  - 不能填 IP、`localhost` 或带端口（[腾讯云：小游戏网络](https://intl.cloud.tencent.com/zh/document/product/1219/68066)）。
- [ ] **7. 准备 AppID 和 AppSecret**：微信、抖音各一套。**AppSecret 只放服务器环境变量**，部署时告诉 agent 变量名即可，不要贴进聊天或仓库。
  - 结果：微信 AppID ____，抖音 AppID ____（只填 AppID）
- [ ] **8. 给部署权限**：服务器上建一个非 root 用户和 SSH 密钥，告诉 agent 登录方式。agent 部署前会再次和你确认。

内测前要定好美术风格，所以下面 12–14 现在就要做，它们决定内测什么时候能开。

- [x] **12. 水墨样张**（I1，**现在**）：agent 出标题页、战斗页两屏样张和一只精怪的立绘样张，你看了说"行"再全量改。
- [x] **13. 书法标题字体**（2026-11-01 选定马善政楷书，已接入）（I1，**现在**）：从下面挑一款。2026-11-01 调研，以字体官方许可为准：

    - 马善政楷书 Ma Shan Zheng：毛笔楷书，偏粗，最贴水墨标题。[许可](https://raw.githubusercontent.com/google/fonts/main/ofl/mashanzheng/OFL.txt)
    - 志莽行书 Zhi Mang Xing：行书，灵动。[许可](https://raw.githubusercontent.com/google/fonts/main/ofl/zhimangxing/OFL.txt)
    - 龙藏体 Long Cang：草书，细长流动。[许可](https://raw.githubusercontent.com/google/fonts/main/ofl/longcang/OFL.txt)
    - 流江毛草 Liu Jian Mao Cao：狂草，笔力重，但不好认。[许可](https://raw.githubusercontent.com/google/fonts/main/ofl/liujianmaocao/OFL.txt)
    - 霞鹜文楷 LXGW WenKai：规整楷体，不是毛笔味，作稳妥备选。[说明](https://raw.githubusercontent.com/lxgw/LxgwWenKai/main/README.md)
