### 2.4 长夜·合体

- 带合体精怪通关经典/苛令解锁。规则同无尽，外加：选完初始后全部随机合体；遇敌全部合体；未合体精怪种族值减半；双生契降为上档、权重 4（需队内 ≥2 未合体）。

### 2.5 苛令

通关经典解锁。可叠多条（不限 3）。非法精怪可收、可移佩，不可上场；非法异相不加气运。败北才算失败，收了非法不废档。

必须实现这 5 条（不要自造「禁捕捉/禁回复」）：

1. **单谱系**：只准上场某批次 1–9；邪社/四座/盟主用该批次编制；合体一方非法则整体非法。
2. **单灵性**：只准上场含该灵性者；可选「进化后才获得该灵性」的初始，进化前不可上场；显圣若改灵性可能变非法；灵极不改变合法性。
3. **白纸开局**：仅三初始，骨相全 10，性灵中庸，无卵术/异相/额外魂契/形态，费用回默认；波 190 后不可收契。临时限制，不改账号。
4. **克制翻转**：2 倍与 0.5 倍对调；免疫视为 2 倍；中性仍中性。镇世兽专属术替换为霆术。
5. **骨相乱序**：HP↔速度、物攻↔特防、物防↔特攻（敌我都洗）。

翻转与乱序互相屏蔽对方苛令成就，其余成就可拿。通关按组合发缎带与孵券。

## 4. 战斗

指挥四项：**术、队伍、囊、走**。

结算管线（独立实现，勿抄类名）：

1. 速度（含先制、迟攻、乱流天时）
2. 能否使出（封印、禁用、挑拨、重力、灵力不足 → 挣扎）
3. 命中 / 守护 / 免疫
4. 伤害：`power * atk/def * levelScale * 灵性修正 * 本系加成 * 天时/地脉 * 暴击 * 乱数 * 骨相 * 佩饰 * 魂契`
5. 附加：状态、能力级、场地、换人、多段、蓄力、反伤
6. 濒死、还魂、升级、进化、学术、换人

必须有：

- 单打与双人（诱饵提高双人遭遇；无尽头目战不可双人）
- 能力级 ±6；灼、麻、眠、冻、毒、剧毒；混乱、畏缩、着迷
- 天时：晴、雨、沙、雪、雾、烈日、暴雨、强风
- 地脉：雷、草、念、雾
- 场地：钉、毒钉、石、网；壁、光壁、雪幕；戏法空间、魔法空间、奇妙空间；重力、顺风
- 替身、守、看破、乌冬、先制、必中、一击、反伤、吸取、束缚、再行动失败
- 魂契可组合效果块（不写巨型 switch）
- 佩饰持有物在场结算；灵果触发；局外魂契（拾遗等）非法体不触发
- 战斗中升级学术、进化、换人、濒死、还魂
- 显圣 / 巨灵 / 灵极（各一套规则，内容原创）
- 头目多段护盾；镇世兽二阶段：清状态、回盾+1、给迷途吞、猛升一项能力、转双人、专属术；超闸时专属炮按超出比例加威力
- 训练师 AI：倾向有效术、补刀、换克制
- 收契：镇物倍率 × 残血 × 气运 × 机缘；头目仅末盾可收；暴契（捕捉符叠层）
- 逃走：野遇可走，训练师不可
- 队伍上限 **6**。经典闸内经验衰减。

镇物至少 5 种倍率：1 / 1.5 / 2 / 3 / 必中。

## 6. 境域

- 开局在「镇」。离镇后才出随机训练师。镇的山河图选项：野原 / 坊市 / 河泽。
- 第一阶段 ≥12 境域可跑通经典 200；无尽阶段邻接图规模 ≥30（原创名，结构对齐公开「邻接 + 权重」）。
- 每境域：野生池（凡/稀/极）、头目池、天气倾向、城主编制、训练师池、昼夜（用波次奇偶）。
- 归墟：经典 191–200；无尽每 50 波。

建议 12 境域名：镇墟、野原、密林、坊市、河泽、荒原、山腹、社坛、洞窟、雪原、潮汐、归墟。后续扩：夜市、矿脉、塔林、海岛、工坊、墓园、星潭、实验室等价原创位。

## 8. 奇遇

- 经典/苛令波 10–180，低概率替换野战。

## 9. 合体

- 双生契：主身 + 祭身。灵性各取一；术 2+2；魂契主身；骨相主身。
- 解除：祭身消失。
- 野生合体仅长夜·合体、合印、或奇遇。
- 收契只记主身。

## 10. 卵、孵券、灵糖、异相

- 孵券：凡 / 上 / 特 / 金 → 1 / 5 / 10 / 25 卵。Pity：特保稀、金保史诗。
- 来源：城主/邪社主/四座/盟主/通关/无尽每 50 波；商店随机（见 5.2）。
- 大厅三机：种族偏向 / 卵术偏向 / 异相偏向。金池每日轮换传说池。
- 卵入槽，战斗回合作步数，到点开卵；可跳过动画。
- 卵术 4 个每种族，用灵糖或孵化解锁。
- 异相 3 档，气运影响野遇与商店升档；异相符只加野遇，不加孵化。
- 亲密度 → 灵糖；捕捉/孵化也给。
- 气运：未濒死的异相队友提供；非法苛令体不加。
