# B5c：风格统一（2026-11-01）

> **上游：** [内测路线图](./2026-10-01-internal-beta-roadmap.md) B5。负责人反馈（看完 B5b 截图）："布局比原来正常了，但所有按钮字体和背景等等都有问题，需要保持风格一致"。
> 观感真源：[../specs/2026-10-29-ink-design.md](../specs/2026-10-29-ink-design.md)。前一轮：[2026-11-01-B5b-ui-polish.md](./2026-11-01-B5b-ui-polish.md)。

**Goal：** 每一页看起来都是同一套水墨界面：同一种字、同一种按钮、同一种面板，背景和内容不打架，没有英文或内部字段漏到界面上。

## 问题清单（来自 390×844 全部 12 页截图，`/tmp/cdp/style1/`）

| # | 问题 | 页面 |
|---|---|---|
| 1 | **两种字混用**：标题是书法字，按钮和正文是系统黑体，看起来像两套界面 | 全部 |

## 方案

### Task 1：全界面统一用书法字（#1）
- 证据：收集了表数据和全部界面源码里可能出现的 916 个汉字与中文标点，马善政楷书只缺一个间隔号 `·`；按这批字子集化约 700 KB（只放 ui-art 分包，不进主包）。
- [ ] 子集改为"全部界面用字"；缺的 `·` 在文案里换成 `、` 或空格（只动展示文案，不动数据 id）。
- [ ] `addLabel` 和按钮文字默认用书法字；数字（HP、金、波次）也用它（马善政的数字是毛笔体，和整体一致）。
- [ ] 字体未加载时回退系统字，不留空白（已有）。
- [ ] 加一个检查：`tools/` 里扫描界面文案，出现子集外的字就报错，防止以后加文案后漏字。

### Task 2：一种按钮、一种面板（#2、#3）
- [ ] 按钮只保留两态：**主行动**（朱砂底、宣纸色字）和**普通**（宣纸底、浓墨字、淡墨细边）；禁用 = 普通态降低不透明度 + 下方原因。列表行、弹层行、模式按钮都用普通态，不再有第三种灰条。
- [ ] 形状：圆角从 12/16 降到 6，边线用不等宽的"墨线"（上下略粗、左右略细），去掉网页式的均匀灰描边。
- [ ] 面板：宣纸底加 85% 不透明度，让背景的墨色淡淡透出；去掉灰描边，改为四角一点淡墨角花（程序化画，不用贴图）。
- [ ] 契约测试：`u16-skin-skeleton.test.ts` 断言按钮只有 primary / normal 两套取色。

### Task 3：文案（#4、#5、#6）
- [ ] 设置分组显示中文名：通用、显示、声音、玩法、操作。
- [ ] 契录未见过的精怪显示剪影名"？？？"加灵性，而不是 8 行一样的"未知"；已见过的显示名字。
- [ ] 存档页说明改短并允许换行，不越界。

### Task 4：背景与内容的关系（#7、#8、#9）
- [ ] 大厅类页面（设置、契录、卵房、成就、统计、存档、名词）和模式页用 `bg_indoor`（画面中间更空），标题贴近面板顶部；内容块整体垂直居中。
- [ ] 面板后面加一层淡宣纸遮罩，背景插画不再穿过按钮。
- [ ] 标题下的计数小字（共 N 项、进度 x / y）合成一行放在标题右侧或面板顶部，不再三四行堆叠。

### Task 5：选宠卡片（#10）
- [ ] 竖屏改为三张横向大卡上下排列：左边立绘、右边名字、灵性、费用；点整张卡选中。横屏保持三列。
- [ ] 版式测试改为"立绘边长 ≥ 卡片短边的 80%"，替换原来的"卡片 ≥ 屏高 30%"（这条规则导致卡片窄高）。

### Task 6：验证
- [ ] `pnpm test`、`pnpm check:forbidden`、`pnpm check:pack`、`assets/scripts/app/` strict 类型检查。
- [ ] 重建试玩包，12 页 × 390×844 与 1280×720 截图逐张看；越界与字号量测保持 B5b 的结果。
