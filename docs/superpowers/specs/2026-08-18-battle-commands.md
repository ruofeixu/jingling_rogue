## 指挥（战斗中）

右侧术签不变。下方偏左三键，**不得挡住术签**：

| 键 | 作用 |
|----|------|
| 队伍 | 换未倒下的精怪；敌方仍会出手 |
| 囊 | 打开子页：丹药、镇物 |
| 走 | 仅野遇；行者战点了提示「不能走」 |

开局带 **小药 2、凡镇 5**。点囊不再因为 0 药直接失败。

### 囊

- **小药**：当前上场回血，消耗 1，敌方出手。
- **凡镇 / 上镇 / 特镇 / 奇镇 / 劫镇**：仅野遇且本波可收契。消耗 1，按残血与镇物倍率掷收契。成则入队（不满 6）并跳过战后收契提示，进坊市；败则敌方出手。
- 行者战、头目未到末盾：镇物不可用，点了说明原因。

战后「镇物 / 放过」仍保留（打倒后的收契）。

## 大厅名词

标题菜单里有完整签条 **「名词」**，不要只靠角落小问号。点开词条，底部显示释义。

## 验收

1. 标题能看到并点开「名词」。
2. 野遇能走，走后进下一流程（坊市/境域），不卡住。
3. 囊能选药和镇物；凡镇可在残血时收契。
4. 术签不被「走」挡住。
