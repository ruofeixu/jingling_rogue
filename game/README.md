# Cocos 工程

用本机已装的 **Cocos Creator 3.8.2** 打开本目录（不要用 3.7 / 2.4）。

1. 打开 `/Applications/Cocos/Creator/3.8.2/CocosCreator.app`
2. 选择「打开其他项目」，选这个 `game/` 文件夹
3. 第一次打开会生成 `library/`、`temp/`，等导入结束
4. 资源管理器里新建 2D 场景（例如 `boot`），把 `assets/scripts/Boot.ts` 挂到 Canvas 上，再点预览

微信/抖音包：菜单「项目 → 构建发布」。`templates/` 里是分包配置参考，构建面板里再勾对应平台。
