## 统一风格锚（所有精怪共用）

- 中国志怪卡通、明亮勾线、圆角、**Q 版全身**、大眼睛。
- 赛璐璐体积：少数大色块 + 二三档明暗 + 一块高光（要读得出圆和厚，不是纯色贴纸）。
- 气质：国产儿童向卡通「好认、圆、鲜」。**不是**日式宠物、**不是**年画暗调。
- **RGBA 透明底，禁止在图里烘焙圆形/椭圆垫底**。正面或四分之三视角、全身、脚下留空。
