# 契灵志怪 — IP 圣经

## 世界观（一句话）

人间城邑与山野之间有「隙」，隙中精怪可被镇物暂契。玩家是游方契士，以一局长征收集契录，失败则局内队伍消散，契录仍在。

## 美术方向

中国志怪卡通：明亮勾线、圆角、Q 版全身。赛璐璐体积：一只精怪仍是少数大色，但要有二三档明暗加一块高光，读得出圆和厚。  
禁止毛发丝、木纹石纹、书法小字、绳结流苏；也禁止回到无阴影的纯色块贴纸。浅底界面（天/纸要亮，字要深）。  
参考气质是国产儿童向卡通的「好认、圆、鲜」，不是碑刻年画暗调，也不是日式宠物。

禁止：官方宠物换色/换描边；别家卡通角色换皮；常见官方龙/鼠/龟/蛙剪影。  
允许：大眼睛卡通精怪，只要仍是本项目原创剪影（灶狸、井蛛、桃梗等）。

立绘：RGBA 透明底，禁止在图里烘焙圆形/椭圆垫底。选初始与战斗必须等比 contain，不得按框硬拉。

## 八灵性

炎、潮、岩、木、霆、霜、影、光。代码：`flame` `tide` `stone` `wood` `bolt` `frost` `shade` `light`。

不要扩展成十八系，不要使用火/水/草/电/冰/龙/妖等宝可梦系名作为产品文案。
