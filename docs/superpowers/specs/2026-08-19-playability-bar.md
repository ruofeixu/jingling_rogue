## 观察面

无头对局只读玩家 HUD 能看见的信息：

- 波次、金钱、小药、镇物数量
- 队伍：名、当前/最大 HP、灵性、术名/灵性/威力/剩余灵力
- 场上敌：名、HP、灵性
- 坊市三选：名称、kind 文案、再择花费
- 当前等待：出术 / 换人 / 点目标 / 收契 / 择境

不提供：隐藏种族值、未上场敌编制、未来波次、内部 RNG 状态。

## 三档策略

| 档 | 行为 | 目标（≥200 种子） |
|----|------|-------------------|
| 低 | 永远第一张术；不换人、不喝药、不收契；坊市拿第一格 | 平均最高波 15–25 |
| 中 | 打克制、残血喝药、换人、收常见种、商店优先攻/药/体 | 平均最高波 40–60 |
| 高 | 中 + 双人点目标 + 再择估值 + 经验/进化优先 + 无利则走 | 经典 200 通关率 40–60% |

达不到则改公开口径数值，不给策略开作弊视野。

命令：`pnpm sim:bench --tier all --seeds 40`（PR）/ `--seeds 200`（夜间）。

## 上手

- 标题 → 模式 → 初始 → 开战 ≤ 3 次确认
- 前 10 波死点击率 < 5%（点了状态不变）
- 引导策略（第一张术 + 残血喝药）10 波存活率 ≥ 80%
- 指挥格互不重叠（现有 layout 测）

## 成长与模式

- 卵房可孵；开局契印三选一（账号解锁）
- 短征 20 波，必选契印
- 五模式规则必须可测且互不相同
