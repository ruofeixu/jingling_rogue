# 卡通厚涂可爱风 UI 设计稿（选型用）

方向：**卡通厚涂可爱风，参考洛克王国世界的界面质感**——粗描边、大圆角、糖果色、
柔和外阴影 + 顶部内高光、圆润无衬线字。偏可爱。

> 这些是 **HTML/CSS 设计稿，仅用于选型**，不是 Cocos 实现。选定风格与布局后再落到引擎。

## 怎么看

- 浏览器直接打开 `docs/ui/design-mockups/*.html`（同一页并排放了多个变体，最直观）。
- 或看已渲染的图：`docs/ui/design-mockups/renders/{title,battle,outcome-shop}.png`。
- 每个手机框顶部有灰字标注变体名（如「变体 A · 网格大厅」）。

## 共享视觉底座（base.css）

所有变体共用一套糖果色 token 与卡通控件，选定后这套直接映射到 Cocos 的 token 层：

- **配色**：天空蓝底 `#eaf4fd`、奶白面板 `#fffdf6`、暖棕字 `#4a3b2f`、蓝描边 `#6fbdf0`、
  主行动橙 `#ff9a4d`、血条绿 `#6ed07a`、敌方红 `#ff8f8f`、金 `#ffd24d`。
- **控件质感**：厚描边（4–6px）、大圆角、按钮底部有一条深色"立体投影边"（按下去的厚度感）、
  面板有外阴影 + 顶部内高光。
- **主/次按钮**：主行动 = 橙色渐变 + 白字 + 描边阴影；次要 = 浅橙底 + 棕字。

## 1. 标题 / 大厅页（title.html）

**功能**：游戏入口。展示游戏名与吉祥物，提供「开始新一局」主按钮和进入各功能页的入口
（契录图鉴、孵化卵房、成就、统计、设置、存档）。

**元素**：
- 顶部：游戏名大标题（描边字）+ 副标题胶囊「精怪肉鸽 · 收集回合」。
- 中部：吉祥物圆形头像（占位表情，后续换立绘）。
- 下部：主按钮「▶ 新的旅途」+ 功能入口按钮组（每个带彩色小圆图标）。

**三个变体**：
| 变体 | 布局 | 特点 |
|---|---|---|
| A · 网格大厅 | 主按钮 + 2×6 图标网格 | 功能全部平铺，一屏可见，信息密度高 |
| B · 告示板 | 功能收进一块木牌告示板 | 有"主菜单"牌头，更聚拢、更有场景感 |
| C · 竖排大按钮 | 主按钮 + 竖排大条目 | 按钮大、好点，但一屏放的功能少 |

## 2. 战斗页（battle.html）

**功能**：回合制战斗主界面。上方显示敌我双方，下方给四个命令：术（出招）、队伍（换位）、
囊（用道具）、走（逃跑）。

**元素**：
- 顶部状态条：第几波、金钱、队伍人数。
- 战场：草地背景，右上敌方立绘 + 名牌（名字/等级/红血条/HP 数值），左下我方立绘 + 名牌（绿血条）。
- 战况气泡：一行提示当前该做什么。
- 命令区：术（主行动橙色）/ 队伍 / 囊 / 走，各带图标。

**两个变体**：
| 变体 | 命令区 | 特点 |
|---|---|---|
| A · 2×2 命令网格 | 四个方块按钮 2×2 | 按钮大、对称、拇指好点 |
| B · 横排托盘 | 底部一排四个竖图标按钮 | 战场更高更大，命令占用更少 |

---

## 3. 结算 / 货摊页（outcome-shop.html）

**结算·胜局**
- **功能**：一局结束后的战果展示与收下。
- **元素**：顶部金色飘带「胜局」+ 吉祥物 + 战果面板（结果/最深波数/金钱/收服数）
  + 主按钮「收下这一局」+ 次按钮「回大厅」。

**货摊**
- **功能**：局内商店，花金钱买道具，或离开继续。
- **元素**：顶部标题 + 金钱胶囊 + 货架（每件道具：图标 / 名字 / 价格；买不起的置灰并写"还差多少"）
  + 主按钮「离开货摊，继续赶路」。
