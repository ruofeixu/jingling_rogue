# 可内测预览界面

> 范围：五种模式可开、大厅齐全、战斗像样。原画用代码剪影，不进 PNG。不做规格第 16 节剩余内容填满。

## 成功标准

预览 `http://localhost:7456/`：

1. 画布按竖屏 750×1334，不是 1280×720 横屏字。
2. 标题可进模式 / 设置 / 契录 / 卵房 / 成就 / 统计 / 存档。
3. 五种模式都能选初始开局。
4. 战斗：中景双方剪影 + 血条，右侧竖列术签，上方队伍 / 囊 / 走（野遇）。
5. 商店、收契、境域、奇遇、败北 / 通关是签条面板，不是一排黄字。

## 布局（原点在画布中心）

- 敌方剪影 `(0, 240)` 宽 200 高 260
- 己方剪影 `(0, -40)` 宽 200 高 260
- 术签列 `x = 250`，自上而下，宽 168 高 70
- 指令条 `y = 560`：队伍 / 囊 / 走
- 日志 `y = -560`

灵性色：炎朱红、潮青、岩赭、木绿、霆金、霜白青、影墨、光杏。
