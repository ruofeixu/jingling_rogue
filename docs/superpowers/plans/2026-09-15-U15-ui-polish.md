# U15：UI 打磨（2026-09-15）

**触发：** 逐张肉眼验收 U6–U11 截图，发现此前"只验几何数据不看画面"漏掉的一批真实缺陷。

**前置：** U14 已让 presentation 页成为不透明独立画面（背景遮盖旧 Boot）。

## 根因（写进规范防再犯）

之前的验证脚本只断言几何数据（节点数、按钮尺寸、hosts=1），就判"渲染通过"，
**没有逐张用眼睛看截图**。结果两个缺陷被长期掩盖：
1. AppShell 叠在旧 Boot 界面上（U14 已修：加铺满背景）。
2. 布局/文案缺陷（本阶段修）。

**教训已写入 `docs/superpowers/specs/2026-08-31-ui-productization.md` 验证章节：
凡是产出截图的验证，必须逐张肉眼查看，不得只凭几何断言判过。**

## 要修的缺陷（肉眼确认）

1. **文案泄漏**：`accessibleName` 被当成可见标题。title 显示"契灵志怪 标题大厅"，
   "标题大厅"是无障碍名，不该给玩家看。排查所有页。
2. **主次按钮视觉层级**：胜局的 `收下这一局`(commit=primaryAction) 在最底、用次要样式；
   `回厅`(次要) 反而在上面。primaryAction 必须主色 + 位置突出。
3. **货摊重复项**：`离开货摊` 出现两次（主行动 + 列表项/文字）。只应一次。
4. **垂直布局**：内容挤在两端，中间大片空白。竖版应更充分利用纵向空间。
5. **battle 战场**：只有名牌框，中段空。名牌间距与信息密度可优化（立绘接入属后续，本阶段先排版）。

## 交付

| 文件 | 改动 |
|---|---|
| `assets/scripts/app/ui/Text.ts` 或各 Screen | 标题只用 model 里的展示文案，不用 accessibleName |
| `assets/scripts/app/screens/*.ts` | 主次按钮层级、垂直布局 |
| presentation builder（如需） | 确保 primaryAction/secondary 语义清晰，列表不与主行动重复 |
| `packages/presentation/src/*` 契约测试 | accessibleName 不进 lines；primary 唯一且不与 secondary 重复 |

## 失败测试（先 RED）

1. 任何页的 `model.lines` 都不得包含 `model.accessibleName` 整串（文案泄漏守卫）。
2. progress/outcome：`primaryAction.id` 不得同时出现在 `secondaryActions` 里（去重）。
3. 货摊：`shop.leave` 只作为 primaryAction 出现一次。

## 退出门

- 5 类缺陷修复；逐张肉眼重拍确认。
- 新增守卫测试防文案泄漏与主次重复。
- U1–U14 无回归；两平台主包 ≤4 MiB；发布审计 PASS。

### 修复项（逐张肉眼确认）

1. **文案泄漏**：title accessibleName 由 `契灵志怪 标题大厅` 改为 `契灵志怪`；
   starter 去掉 `立绘 ${art}` 行（ArtState 内部值不再泄漏给玩家）。守卫测试钉死。
2. **主次按钮层级**：ListView 与 StarterScreen 的 primaryAction 改为紧跟内容下方、主色突出，
   不再钉在屏幕最底与内容脱节。
3. **货摊重复项**：确认 `shop.leave` 只作为 primaryAction 出现一次（守卫测试验证 secondary 不含 primary）。
4. **垂直布局**：ListView 内容按预估总高整体居中偏上；StarterScreen 底部按钮紧跟详情。
   消除了此前"内容贴顶、下半屏大片空白"。

### 根因与规范（防再犯）

前几轮验证只断言几何数据（节点数、按钮尺寸、hosts）就判过，未逐张肉眼看图，
导致叠加穿透与布局/文案缺陷被长期掩盖。已在
`docs/superpowers/specs/2026-08-31-ui-productization.md` 6.1.1 新增强制条款：
**任何产出截图的验证必须逐张肉眼查看，几何断言只作补充，不得替代看图。**

### 遗留（需真机/后续）

- starter 三张卡片立绘为空（占位）；真机接立绘属后续。
- battle 战场中段留白待立绘接入后自然填充。
- 减少动效/200% 文本/横屏的逐张肉眼复看，建议下轮补齐（本轮聚焦竖屏 normal 态缺陷）。
